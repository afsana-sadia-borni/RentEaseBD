# 🏠 RentEase BD

RentEase BD is a modern web-based rental management platform designed to streamline house and property rentals in Bangladesh. It connects property owners (landlords) with potential tenants through an intuitive and feature-rich interface.

---

## ✨ Features

- **User Authentication & Roles:** Role-based access control for **Landlords** and **Tenants**.
- **Property Listings:** Landlords can easily list properties with title, rent, location, description, and high-quality image uploads.
- **Interactive Map Integration:** Integrated Leaflet map for precise location picking and property viewing via Latitude & Longitude.
- **Booking Management:** 
  - Tenants can request and manage their property bookings.
  - Landlords can review and track incoming bookings for their properties.
- **Payment Gateway Integration:** Integrated payment flow for property bookings with status updates.
- **Reviews & Ratings:** Tenants can leave feedback and ratings on rental listings.
- **Responsive & Modern UI:** Designed with modern HTML5, CSS3, Bootstrap 5, and smooth AOS animations.

---

## 🛠️ Tech Stack

- **Backend:** Python 3.12, Django 6.0
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Database:** SQLite (Local) / PostgreSQL (Neon DB Cloud)
- **Map Library:** Leaflet.js / OpenStreetMap
- **Version Control:** Git & GitHub
